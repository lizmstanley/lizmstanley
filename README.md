## Hi, I'm Liz.

I'm a senior backend engineer focused on databases and data access: schema design, migrations, multi-tenancy, transactions, and the code that talks to them. Most of my work is Postgres, Python, TypeScript, AWS, and Terraform. I use AI as a force multiplier for my engineering judgment. I own the design, and I check what it produces the way I'd check a teammate's code.

My resume is at [lizstanley.com/resume](https://lizstanley.com/resume/).

I've also been the compiler for the [Bloomington, MN Christmas Bird Count](https://www.bloomingtoncbc.org/) since 2020. It's a complex circle, with 24 areas and 60+ field observers, so a lot of what I build outside of work is for it.

### Projects

- [cbc-circle-manager](https://github.com/lizmstanley/cbc-circle-manager) - Browser-based tool for CBC compilers to manage volunteers, area assignments, outreach, maps, and results. Local-first, so the data stays in your browser. Includes Circle Scout, a phone app that shows counters their area, where they are, and what's been seen nearby.
- [cbc_utils](https://github.com/lizmstanley/cbc_utils) - The earlier set of scripts for the same job: mapping, pulling eBird data, and automating data entry on the Audubon website.
- [mou-utils](https://github.com/lizmstanley/mou-utils) - Pulls reports from the Minnesota Ornithologists' Union website and saves them as CSV. The site has no API, so this uses web automation.
- [webcam-weather](https://github.com/lizmstanley/webcam-weather) - Overlays live data from my Davis weather station on an Axis webcam video.
- [to-unit-decorator](https://github.com/lizmstanley/to-unit-decorator) - TypeScript decorators that convert between units of measure, and an example of how method and parameter decorators work.
- [simple-node-transform-stream](https://github.com/lizmstanley/simple-node-transform-stream) and [node-transform-stream](https://github.com/lizmstanley/node-transform-stream) - Examples of processing data with Node.js transform streams, including database backpressure.
